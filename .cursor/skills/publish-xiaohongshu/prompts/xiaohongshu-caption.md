# 小红书文案生成指令

为「智者周刊」某一期生成小红书图文笔记文案。

## 输入

- 人物名（中/英）、tagline、本期核心主题
- `wechat-article.md` 或 PDF 章节要点（缩短，不要全文照搬）
- 目标：生活方式 / 个人成长 / 读书思考 类受众

## 输出文件格式

写入 `xiaohongshu-post.md`：

```markdown
---
title: ""
tags: []
visibility: "公开可见"
---

（正文）
```

## 标题（≤20 字）

- 有悬念或反差，可带人物名
- 示例：「纳瓦尔：聪明人为什么不快乐？」「每周一个智者｜第1期」

## 正文（≤1000 字）

结构建议：

1. **钩子**（1–2 句）— 问题或反常识
2. **核心观点**（3–5 条 bullet 或短段）— 来自本期洞察，每条 2–3 句
3. **金句**（1 条中英或中文）— 可引用人物原话
4. **行动号召** — 「收藏慢慢看」「关注每周更新」「左滑看完整卡片」
5. **话题引导** — 正文末尾可写 `#成长 #思维`（tags 也会在发布时单独传）

风格：口语化、有温度，不像论文；适度 emoji（每段最多 1–2 个）。

## 标签 tags（3–5 个）

与内容相关，如：成长、读书、纳瓦尔、人生智慧、智者周刊

## 禁止

- 标题超 20 字、正文超 1000 字
- 外链、微信号、明显引流
- 编造人物没说过的话
