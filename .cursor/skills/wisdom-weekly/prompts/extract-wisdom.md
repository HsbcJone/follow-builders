# 智慧提炼指令

你正在为「智者周刊」提炼一位智者的核心洞察。目标是生成 3-5 个深度洞察，用于制作精美 PDF 和公众号文章。

## 输入

你会收到一个人物档案（.md 文件），包含：
- 基本信息（名字、标签、风格）
- 核心哲学概述
- 重点提炼方向
- 标志性语录
- 代表作品列表

## 输出格式

为每个洞察生成以下结构：

```
### 洞察标题（中文，6-12 字）

**中文解读**（2-3 段，共 200-300 字）：
- 第一段：用一个场景或故事引入，让读者产生共鸣
- 第二段：解读核心思想，说清楚「为什么」
- 第三段（可选）：延伸思考或与当下生活的连接

**CORE INSIGHT 金句**（1-2 句，中文提炼，简洁有力）

**原文引用**（英文或中文原文，来自人物的真实著作/演讲）
```

## 提炼原则

1. **深度优于广度** — 每个洞察要挖得足够深，不要浅尝辄止
2. **对比产生力量** — 用反常识、对比、悖论来制造张力（例：「生命并不短暂，是我们浪费太多」）
3. **具体胜过抽象** — 用场景和画面感，不用空泛的形容词
4. **中文解读要有温度** — 不是翻译，是用中国读者能共鸣的方式重新表达
5. **原文必须真实** — 只引用此人真实说过/写过的话，不编造
6. **金句要能独立传播** — CORE INSIGHT 必须脱离上下文也能让人产生触动

## 章节组织

- 给 3-5 个洞察安排一个逻辑递进关系
- 每组洞察用一个「CHAPTER」标题统领（中英双语）
- 章节之间的过渡要自然

## 国际人物 vs 国内人物

**国际人物**：中文解读 + 英文原文（Original Text）
**国内人物**：中文解读 + 中文原文引用（不需要英文）

## 篇幅控制

- 整体内容需要填充 3-5 个 PDF 章节页
- 每个章节页包含 1-2 个洞察
- 总字数（中文解读部分）：1500-2500 字
