# 智慧提炼指令

你正在为「智者周刊」提炼一位智者的核心洞察。目标是生成 3-5 个深度洞察，用于制作精美 PDF 和公众号文章。

## 输入

你会收到一个人物档案（.md 文件），包含：基本信息、核心哲学、重点提炼方向、标志性语录、代表作品。

## 每个洞察的输出结构（PDF 用）

```
洞察标题中文 / Insight Title English

【正文 · Body】— 国际人物必须中英成对，国内人物仅中文
段落1 中文
段落1 英文（自然英文，传达相同含义，非机翻腔）
段落2 中文
段落2 英文
…（每页 1–2 组段落，避免挤版）

【核心洞察 · Core Insight】
中文金句（1–2 句）
英文原文或英文金句（来自其真实著作/演讲）
```

## 正文双语规则（重要）

**国际人物（people/international/）**
- 每一段中文解读后，**必须**紧跟对应英文段落
- 英文是「同一意思的流畅表达」，可适度意译，但不可编造 Naval 没说过的事实
- 禁止只有中文正文、只有标题和核心洞察有英文

**国内人物（people/chinese/）**
- 正文仅中文；核心洞察可用中文原文引用（古籍、语录）

## 提炼原则

1. 深度优于广度；对比与反常识制造张力
2. 具体场景胜过空泛形容词
3. 中文有温度；英文简洁、可读（杂志专栏语气）
4. 原文必须真实，不虚构引言
5. 每页约 1 个洞察，正文 1–2 组中英段落 + 核心洞察框

## HTML 片段（填入章节页）

每组正文段落：

```html
<div class="body-pair">
  <p class="para-zh">中文段落</p>
  <p class="para-en">English paragraph.</p>
</div>
```

## 篇幅

- 中文解读单段：60–90 字
- 英文对应单段：40–70 词
- 每期 PDF 正文部分总计约 1500–2200 字（中文）
