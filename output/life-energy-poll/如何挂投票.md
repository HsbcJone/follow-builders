# 小红书投票笔记 — 发布说明

## 为什么 MCP 发的没有投票？

`xiaohongshu-mcp` 的 `publish_content` **只支持图文**（标题 + 正文 + 图片），**不支持**「互动组件 → 投票」。投票只能在 **小红书 App 发布页** 里添加。

---

## 已发出去的那条怎么办？

**已发布笔记一般不能事后加投票**（编辑只能改标题/正文/封面，没有「补挂投票」入口）。

推荐二选一：

### 方案 A（推荐）：App 重发一条带投票

1. 把现在这条 **删了** 或 **设为仅自己可见**（若已有阅读/互动，可保留旧帖，见方案 B）
2. App：**+** → **图文** → 选封面 `note-01/page-01.png`（可从相册选，或 AirDrop 到手机）
3. 填标题、正文（见下方「可复制文案」）
4. **关键：** 在发布编辑页找到 **「互动组件」** 或 **「投票」** → 选 **投票**（不是 PK）
5. 投票问题：`如果只能选一个，最影响你状态的是？`
6. 选项（4 个）：`睡眠` `饮食` `运动` `情绪`
7. 发布

### 方案 B：不重发，用置顶评论代替

在笔记下 **自己发一条评论**，写：

```
帮投一票👇 回复 A/B/C/D 即可
A 睡眠  B 饮食  C 运动  D 情绪
```

然后 **置顶** 该评论。参与率低于原生投票，但不用删帖。

---

## 第 2～5 条怎么发？

**流程：** 本地生成封面 → **在 App 里发布并挂投票**（不要再用 MCP 直接发终稿）。

MCP 可继续用来：登录、备图；**带投票的终稿一律 App 发。**

## note-01 可复制文案

**标题：** 状态差？先投一票

**正文：**

```
最近状态起伏挺大，想先搞清楚主因。

如果只能选一个——睡眠、饮食、运动、情绪，你会选哪个？点一下就行，3 秒搞定。

点个投票，我想看看大家是不是和我一样。
```

**投票：**

| 字段 | 内容 |
|------|------|
| 问题 | 如果只能选一个，最影响你状态的是？ |
| 选项 | 睡眠 / 饮食 / 运动 / 情绪 |
