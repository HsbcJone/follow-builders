## 发闲鱼时建议

1. **配图**：流水线截图 3～6 张（Cursor、小红书已发布、公众号草稿、视频号、产出文件夹）
2. **类目**：选「技能服务 / 咨询 / 电子资料」等与你资质相符的类目
3. **价格**：按你的课程/陪跑定价填写，文案里不写死价格
4. **合规**：勿写「保证涨粉/月入过万」，用「已跑通流程 / 可复现」表述

## 说明

文案强调你已打通：**内容生成 → 小红书自动发 → 公众号草稿 → 视频合成 → 视频号手动发**，适合教想做自媒体变现的学员，**不包含闲鱼自动发布**。
